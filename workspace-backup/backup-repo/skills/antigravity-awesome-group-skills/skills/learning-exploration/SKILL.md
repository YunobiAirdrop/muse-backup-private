# 🎓 Learning / Exploration

> **Group Skill** — Orchestrates sub-skills for learning a new technology or understanding a codebase.
> Activate by saying: "Learn this technology" or "explore codebase"

## When to Use

- Learning a new technology or framework
- Need to understand an unfamiliar codebase
- Exploring and documenting system architecture

## Step-by-Step Workflow

### Step 1: Deep Research
**Skill**: `deep-research` / `search-specialist`
- Conduct comprehensive research
- Find best resources
- Synthesize information

### Step 2: Codebase Analysis
**Skill**: `wiki-architect` / `wiki-qa`
- Understand existing code
- Map module dependencies
- Document key components

### Step 3: Architecture
**Skill**: `c4-container` / `c4-component` / `c4-context`
- Create system diagrams
- Document architecture views
- Map system context

### Step 4: Patterns
**Skill**: `software-architecture` / `domain-driven-design`
- Identify design patterns used
- Learn domain modeling
- Understand architectural choices

### Step 5: Practice
**Skill**: `tdd-workflow`
- Build with test-driven development
- Practice through implementation
- Solidify understanding

### Step 6: Notes
**Skill**: `bulletmind` / `diary`
- Take structured notes
- Document key learnings
- Create reference guides

### Step 7: Share
**Skill**: `content-creator` / `copywriting`
- Write about what you learned
- Create tutorials
- Share with community

## Completion

Technology is learned, documented, and shared. 🎓
