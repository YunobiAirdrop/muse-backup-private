# 📝 Content Creation / Blog Writing

> **Group Skill** — Orchestrates sub-skills for writing blog posts, documentation, or marketing content.
> Activate by saying: "Write a blog post" or "create content"

## When to Use

- Writing blog posts, documentation, or marketing content
- Need SEO-optimized content with proper structure
- Publishing across multiple platforms

## Step-by-Step Workflow

### Step 1: Strategy
**Skill**: `content-strategy`
- Plan content calendar and topics
- Define target audience and goals
- Map content to buyer journey

### Step 2: SEO Research
**Skill**: `seo-fundamentals` / `seo-content`
- Perform keyword research
- Analyze search intent
- Identify content gaps

### Step 3: Writing
**Skill**: `copywriting` / `beautiful-prose`
- Draft compelling content
- Follow brand voice guidelines
- Structure with proper headings

### Step 4: AI Cleanup
**Skill**: `unslop` / `avoid-ai-writing`
- Remove AI writing patterns
- Humanize the text
- Ensure natural readability

### Step 5: Schema
**Skill**: `seo-schema` / `schema-markup`
- Add structured data
- Implement Article/NewsArticle schema
- Validate with testing tools

### Step 6: Publish (WordPress)
**Skill**: `wordpress` / `wordpress-centric-high-seo-optimized-blogwriting-skill`
- Publish to WordPress
- Optimize for platform
- Schedule publication

### Step 7: Publish (X/Twitter)
**Skill**: `x-article-publisher-skill`
- Cross-post to X/Twitter
- Format for platform
- Engage with audience

### Step 8: Analytics
**Skill**: `analytics-tracking` / `google-analytics-automation`
- Track content performance
- Monitor engagement metrics
- Iterate based on data

## Completion

Content is written, optimized, published, and tracked. 📝
