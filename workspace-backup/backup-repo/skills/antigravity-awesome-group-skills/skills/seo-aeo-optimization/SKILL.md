# 📈 SEO / AEO Optimization

> **Group Skill** — Orchestrates sub-skills for optimizing a site for search engines and AI engines.
> Activate by saying: "Run SEO audit" or "optimize for AEO"

## When to Use

- Optimizing a site for search engines and AI engines
- Need to improve organic rankings
- Implementing structured data and content strategy

## Step-by-Step Workflow

### Step 1: Audit
**Skill**: `seo-audit` / `seo-forensic-incident-response`
- Analyze current SEO state
- Identify issues and opportunities
- Benchmark against competitors

### Step 2: Keywords
**Skill**: `seo-keyword-strategist` / `seo-aeo-keyword-research`
- Research target keywords
- Analyze search intent
- Map keywords to content

### Step 3: Technical
**Skill**: `seo-technical` / `seo-hreflang`
- Fix technical SEO issues
- Implement hreflang tags
- Optimize robots.txt and sitemaps

### Step 4: Content
**Skill**: `seo-content` / `seo-content-planner`
- Plan content strategy
- Create SEO-optimized content
- Optimize existing content

### Step 5: Schema
**Skill**: `seo-schema` / `schema-markup`
- Add structured data
- Implement rich snippets
- Validate with testing tools

### Step 6: On-Page
**Skill**: `seo-page` / `seo-meta-optimizer`
- Optimize meta titles and descriptions
- Improve heading structure
- Optimize images and alt text

### Step 7: Internal Links
**Skill**: `seo-aeo-internal-linking`
- Improve link structure
- Build topical authority
- Distribute page rank

### Step 8: AEO
**Skill**: `seo-aeo-blog-writer` / `seo-aeo-content-quality-auditor`
- Optimize for AI engine answers
- Write featured snippet content
- Structure for knowledge panels

### Step 9: Sitemap
**Skill**: `seo-sitemap` / `seo-structure-architect`
- Generate XML sitemaps
- Submit to search engines
- Monitor crawl stats

### Step 10: Monitor
**Skill**: `google-analytics-automation` / `posthog-automation`
- Track rankings
- Monitor traffic
- Report on KPIs

## Completion

Site is fully optimized for search and AI engines. 📈
