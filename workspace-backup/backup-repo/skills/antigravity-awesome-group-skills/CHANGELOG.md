# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-06-22

### Added

- Initial release with **1,449+ agentic skills** organized by domain
- Full reference guide in README.md with skills categorized by:
  - Mission/Task workflows (Pre-Deployment, Dev Setup, Sprint Planning, Debugging, Security, etc.)
  - Technology domains (Frontend, Backend, Mobile, Database, AI/ML, DevOps, Security, Testing, etc.)
- Standard OSS files: LICENSE (MIT), CODE_OF_CONDUCT, CONTRIBUTING, SECURITY
- Directory structure scaffolding for community contributions:
  - `skills/` — Individual skill directories
  - `plugins/` — Plugin bundles
  - `docs/` — User and contributor documentation
  - `scripts/` — Automation scripts
  - `assets/` — Visual assets
- AGENTS.md — AI agent instructions
- package.json — npm metadata
- .github/ templates for issues and PR workflows
