# 🏢 Enterprise / Corporate Project

> **Group Skill** — Orchestrates sub-skills for working within a large organization with compliance and governance.
> Activate by saying: "Enterprise project" or "corporate compliance"

## When to Use

- Working within a large organization
- Need compliance and governance controls
- Implementing enterprise security patterns

## Step-by-Step Workflow

### Step 1: Compliance
**Skill**: `security-compliance-compliance-check` / `gdpr-data-handling`
- Review regulatory requirements
- Implement compliance controls
- Document governance policies

### Step 2: Architecture
**Skill**: `senior-architect` / `microservices-patterns`
- Design enterprise architecture
- Apply microservices patterns
- Document architecture decisions

### Step 3: Azure
**Skill**: `azure-identity-ts` / `azure-keyvault-py`
- Set up enterprise authentication
- Configure key vaults
- Manage service principals

### Step 4: Monitoring
**Skill**: `azure-monitor-opentelemetry-ts` / `datadog-automation`
- Implement enterprise observability
- Set up distributed tracing
- Configure alerting

### Step 5: Secrets
**Skill**: `secrets-management` / `cred-omega`
- Manage credentials securely
- Implement secret rotation
- Audit secret access

### Step 6: CI/CD
**Skill**: `github-actions-templates` / `gitlab-ci-patterns`
- Set up pipeline governance
- Configure approval gates
- Implement deployment policies

### Step 7: Documentation
**Skill**: `api-documentation` / `wiki-architect`
- Build knowledge base
- Document APIs and services
- Create runbooks

### Step 8: Audit Trail
**Skill**: `audit-context-building` / `zeroize-audit`
- Implement audit logging
- Track access and changes
- Generate compliance reports

## Completion

Enterprise project meets compliance, governance, and security requirements. 🏢
