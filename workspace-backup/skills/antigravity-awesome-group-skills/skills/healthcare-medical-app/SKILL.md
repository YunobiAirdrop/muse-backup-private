# 🏥 Healthcare / Medical App

> **Group Skill** — Orchestrates sub-skills for building a health-related application with compliance requirements.
> Activate by saying: "Build a healthcare app" or "medical application"

## When to Use

- Building a health-related application
- Need to comply with healthcare regulations (HIPAA, GDPR)
- Handling protected health information (PHI)

## Step-by-Step Workflow

### Step 1: Compliance
**Skill**: `gdpr-data-handling` / `privacy-by-design`
- Review regulatory requirements
- Implement privacy controls
- Document compliance measures

### Step 2: Data Model
**Skill**: `database-design` / `domain-driven-design`
- Design health data schemas
- Model patient data securely
- Set up audit trails

### Step 3: Analysis
**Skill**: `claude-ally-health` / `family-health-analyzer`
- Process health data
- Run health analyses
- Generate insights

### Step 4: PHI Protection
**Skill**: `secrets-management` / `security-auditor`
- Encrypt protected health information
- Manage access controls
- Audit data access

### Step 5: Dashboard
**Skill**: `kpi-dashboard-design` / `grafana-dashboards`
- Build health metrics dashboards
- Visualize patient data
- Monitor health trends

### Step 6: Reports
**Skill**: `xlsx-official` / `pdf-official`
- Generate health reports
- Export patient summaries
- Create compliance documents

### Step 7: Audit
**Skill**: `security-compliance-compliance-check`
- Verify compliance status
- Run security scans
- Generate audit reports

## Completion

Healthcare application is compliant, secure, and ready for use. 🏥
