# Skills Directory

This directory contains individual skill folders. Each skill has its own `SKILL.md` file with instructions, patterns, and best practices for a specific domain or task.

## Structure

```
skills/
├── my-awesome-skill/
│   ├── SKILL.md      # The skill instructions
│   └── ...           # Optional supporting files
└── another-skill/
    ├── SKILL.md
    └── ...
```

## Creating a New Skill

1. Create a folder with a lowercase-hyphenated name
2. Copy `docs/contributors/skill-template.md` as `SKILL.md`
3. Fill in the frontmatter (name, description, source, date)
4. Write clear, actionable instructions
5. Test with your AI tool
6. Open a PR!

See [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed instructions.
