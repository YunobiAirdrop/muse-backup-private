# Security Policy

## Supported Versions

We recommend using the latest version of the repository.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. We will
investigate all legitimate reports and do our best to fix the issue quickly.

To report a vulnerability, open a GitHub Issue with the label `security`:
- https://github.com/YOUR-USERNAME/antigravity-awesome-group-skills/issues

You can also discuss security concerns in the project's discussion section.

## Responsible Disclosure

We kindly ask that you:

1. Report the vulnerability privately
2. Give us reasonable time to fix the issue before disclosure
3. Do not expose the vulnerability publicly until we have fixed it

Thank you for helping keep this project and its users safe.
