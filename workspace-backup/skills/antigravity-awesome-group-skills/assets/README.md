# Assets Directory

Visual assets for the repository, including:

- Social preview cards
- Logo images
- Hero images
- Screenshots
- Icons

## Usage

To reference an asset in markdown:

```markdown
![Alt text](assets/image-name.png)
```

## Contributing Assets

If you're adding new assets:
- Use descriptive filenames (e.g., `social-card.png`, `logo.svg`)
- Optimize images for web (PNG, JPEG, SVG)
- Keep file sizes reasonable
