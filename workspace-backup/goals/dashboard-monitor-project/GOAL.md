# Dashboard monitor project

Goal ID: goal_b015585b8734
Goal slug: dashboard-monitor-project

## Description
Yunobi meminta dibuatkan website untuk memantau proyek yang lagi jalan dan yang lagi antre agar tidak perlu bertanya terus. Dashboard dibangun dan dipublish ke GitHub Pages dengan update otomatis tiap 30 menit via cron. Atas permintaan user, tiap video kini punya badge SHORT/LONG plus durasi, ada jadwal produksi 18 channel, riwayat upload lengkap dengan tombol 'Buka video', dan tombol 'Salin perintah' untuk video berstatus SIAP agar bisa diupload manual lewat chat; retry otomatis tiap 3 jam juga dipasang untuk mencoba upload video SIAP tanpa ketukan.
