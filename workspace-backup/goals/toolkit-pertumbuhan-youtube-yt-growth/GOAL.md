# Toolkit pertumbuhan YouTube (yt-growth)

Goal ID: goal_4bb1bbe323f2
Goal slug: toolkit-pertumbuhan-youtube-yt-growth

## Description
Toolkit gratis buatan sendiri sebagai pengganti tool SEO YouTube berbayar: membaca analitik asli tiap channel (views, retensi), mendeteksi video ber-CTR rendah, dan me-refresh judul, deskripsi, dan tag via API resmi. Formula judul dan hook dari audit sergebulaev/youtube-skills juga ditanam ke 17 cron channel. Otorisasi OAuth per channel dan jadwal refresh mingguan sedang disiapkan; laporan dikirim setelah selesai.
