PENGAJUAN GOOGLE ADSENSE untuk 10 blog (dijadwalkan 2026-10-03, dieksekusi sekarang).

Konteks: 10 blog Blogger (akuntyunobi17@gmail.com) sudah jalan rutin ~100 artikel/hari sejak 2026-10-03. Sekarang konten seharusnya sudah 2000+ artikel per blog — cukup untuk pengajuan AdSense.

Blog list (cek config di ~/workspace/blog-otomatis/config.json untuk URL):
KabarViral, TEKNO PEDIA, info kesehatan hari ini, ekonomi bisnis info, Gaya Hidup Kekinian, olahraga terbaru, WisataIndo, KulinerNusantara, OtomotifInfo, PendidikanCerdas.

Langkah:
1. Cek tiap blog: pastikan ada 50+ artikel terbit dan tidak ada masalah (buka 2-3 blog acak di browser)
2. Via browser, buka https://www.google.com/adsense/start/ — login dengan akun Google akuntyunobi17@gmail.com (kredensial di Secure Vault, minta user jika perlu OTP)
3. Daftarkan situs pertama (KabarViral). Ikuti proses: isi data → dapat kode verifikasi → pasang kode di tema blog via Blogger dashboard (Tema → Edit HTML, tempel di <head>)
4. Setelah situs pertama terverifikasi, tambahkan 9 situs lainnya di dashboard AdSense
5. Laporkan ke user: status pengajuan per blog + estimasi waktu review Google (biasanya 1-2 minggu) + apa yang harus user siapkan (info pembayaran & pajak nanti saat disetujui)

CATATAN: Jangan janjikan persetujuan — keputusan di tangan Google. Jika ada blog yang kontennya bermasalah, laporkan dan skip dulu blog itu.
