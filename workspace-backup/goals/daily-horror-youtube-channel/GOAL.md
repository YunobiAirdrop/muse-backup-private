# Daily horror YouTube channel

Goal ID: goal_3c4040f91145

## Description
Yunobi approved a fully automatic daily horror-story YouTube channel: one 9-10 minute video (70-80 images, Indonesian voiceover) plus 3 Shorts every day at 17:11. It runs on the Kisah POV channel, which was renamed Kisah Horor with a new horror logo, banner, and description. First story: 'Kuntilanak Beringin Tua: Jangan Lewat Sini Malam Jumat!'
