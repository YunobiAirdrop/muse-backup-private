# YouTube POV channel automation

Goal ID: goal_a181165b60ca
Goal slug: youtube-pov-channel-automation

## Description
Yunobi approved a fully automatic faceless YouTube channel in the POV-history style: first-person dramatic narration with illustrated scenes and Indonesian voiceover, made to look natural rather than AI-generated. The spec is 15-minute videos with 15-20 images each, a different story every day, and automatic titles, descriptions, hashtags, and thumbnails. Uploads run on the existing @ceritarakyat862 channel with daily premieres at 19:00 WIB using FYP-style hooks.
