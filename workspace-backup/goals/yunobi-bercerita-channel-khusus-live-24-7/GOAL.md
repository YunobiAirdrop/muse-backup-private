## Description
Yunobi berencana mengalihfungsikan channel Yunobi Bercerita yang sepi penonton menjadi channel khusus live streaming untuk target anak-anak. Verifikasi nomor HP sudah beres dan stream key sudah diamankan, tetapi tes menunjukkan network server tidak bisa streaming RTMP ke YouTube. Satu-satunya jalan adalah VPS murah, dan keputusannya ada di tangan Yunobi.
