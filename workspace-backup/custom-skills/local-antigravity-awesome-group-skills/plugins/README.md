# Plugins Directory

Plugins are curated bundles of skills organized for specific domains or workflows. Each plugin packages the most relevant skills for a focused use case.

## Structure

```
plugins/
├── web-app-builder/
│   ├── plugin.json     # Plugin metadata
│   └── skills/         # Skills included in this plugin
├── security-engineer/
│   ├── plugin.json
│   └── skills/
└── ...
```

## Creating a Plugin

1. Create a folder with a descriptive name
2. Add a `plugin.json` with metadata
3. Include or symlink the relevant skills
4. Document what the plugin covers
