# 🎮 Game Development

> **Group Skill** — Orchestrates sub-skills for building a game (2D, 3D, or VR).
> Activate by saying: "Build a game" or "game development"

## When to Use

- Building a game in 2D, 3D, or VR
- Need to choose the right game engine
- Implementing graphics and physics

## Step-by-Step Workflow

### Step 1: Engine
**Skill**: `game-development`
- Choose the right platform
- Route to engine-specific skills
- Set up project scaffolding

### Step 2: Godot
**Skill**: `godot-4-migration` / `godot-gdscript-patterns`
- Follow Godot-specific patterns
- Use GDScript best practices
- Implement Godot nodes

### Step 3: Unity
**Skill**: `unity-developer` / `unity-ecs-patterns`
- Apply Unity development patterns
- Use ECS architecture
- Implement Unity systems

### Step 4: Unreal
**Skill**: `unreal-engine-cpp-pro`
- Write Unreal Engine C++ code
- Use Blueprints effectively
- Optimize for Unreal

### Step 5: ECS
**Skill**: `bevy-ecs-expert`
- Build with Bevy ECS in Rust
- Create systems and queries
- Manage resources

### Step 6: 3D
**Skill**: `threejs-fundamentals` / `threejs-animation`
- Create 3D web experiences
- Build Three.js scenes
- Add animations and interactions

### Step 7: Physics
**Skill**: `shader-programming-glsl`
- Write custom shaders
- Implement visual effects
- Optimize rendering

## Completion

Game is built with the right engine, architecture, and visuals. 🎮
