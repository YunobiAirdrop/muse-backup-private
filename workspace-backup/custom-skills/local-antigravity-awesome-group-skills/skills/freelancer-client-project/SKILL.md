# 💼 Freelancer / Client Project

> **Group Skill** — Orchestrates sub-skills for managing a client-facing development project.
> Activate by saying: "Start a client project" or "freelance project"

## When to Use

- Managing a client-facing development project
- Need to scope, build, and deliver a project
- Handling client communication and handoff

## Step-by-Step Workflow

### Step 1: Scope
**Skill**: `writing-plans` / `product-manager-toolkit`
- Gather requirements
- Define deliverables
- Set project milestones

### Step 2: Proposal
**Skill**: `pr-writer`
- Write client proposal
- Define timeline and costs
- Set expectations

### Step 3: Architecture
**Skill**: `senior-architect` / `software-architecture`
- Make technology decisions
- Design system architecture
- Document trade-offs

### Step 4: Build
**Skill**: Use relevant framework skills
- Implement features
- Follow best practices
- Iterate based on feedback

### Step 5: Test
**Skill**: `tdd-workflow` / `e2e-testing`
- Ensure quality assurance
- Write automated tests
- Run manual testing

### Step 6: Deploy
**Skill**: `vercel-deployment` / `docker-expert`
- Deploy to production
- Configure domains
- Set up monitoring

### Step 7: Docs
**Skill**: `wiki-architect` / `api-documentation`
- Create client documentation
- Write handoff guide
- Document architecture

### Step 8: Invoice
**Skill**: Use relevant business tools
- Generate invoice
- Track payments
- Manage follow-ups

## Completion

Client project is delivered with documentation and handoff. 💼
