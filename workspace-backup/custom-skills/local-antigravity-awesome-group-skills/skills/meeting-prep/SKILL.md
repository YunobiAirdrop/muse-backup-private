# 🎙️ Meeting Prep / Standup

> **Group Skill** — Orchestrates sub-skills for preparing for meetings, standups, and sprint reviews.
> Activate by saying: "Prep for meeting" or "standup notes"

## When to Use

- Preparing for a standup, sprint review, or client meeting
- Need to document progress and decisions
- Creating demo materials

## Step-by-Step Workflow

### Step 1: Status Check
**Skill**: `conductor-status` + `diary`
- Review what's been completed
- Check current task status
- Identify blockers

### Step 2: Progress Review
**Skill**: `planning-with-files` + `context-management-context-save`
- Review session context
- Summarize progress made
- Note key decisions

### Step 3: Demo Prep
**Skill**: `remotion` + `frontend-slides`
- Create walkthrough video
- Build presentation slides
- Prepare live demo

### Step 4: Notes
**Skill**: `bulletmind`
- Structure meeting notes
- Create agenda items
- Prepare discussion points

### Step 5: Follow-ups
**Skill**: `diary`
- Log decisions and action items
- Track open questions
- Document next steps

### Step 6: Action Items
**Skill**: `jira-automation` / `linear-claude-skill` / `trello-automation`
- Create tickets for action items
- Assign owners and deadlines
- Set priorities

## Completion

Meeting is prepared with status, demo, notes, and action items ready. 🎙️
