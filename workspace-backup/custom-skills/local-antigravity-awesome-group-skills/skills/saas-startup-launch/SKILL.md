# 💰 SaaS / Startup Launch

> **Group Skill** — Orchestrates sub-skills for building and launching a SaaS product.
> Activate by saying: "Launch a SaaS" or "startup launch"

## When to Use

- Building and launching a SaaS product
- Need to validate business idea and go to market
- Setting up payments, auth, and analytics

## Step-by-Step Workflow

### Step 1: Validation
**Skill**: `startup-business-analyst-business-case`
- Define business case
- Validate problem-solution fit
- Assess market need

### Step 2: Market
**Skill**: `startup-business-analyst-market-opportunity`
- Size the addressable market
- Analyze competitors
- Identify target segments

### Step 3: Pricing
**Skill**: `pricing-strategy`
- Define monetization model
- Set pricing tiers
- Test willingness to pay

### Step 4: MVP
**Skill**: `saas-mvp-launcher`
- Define MVP scope
- Choose architecture
- Build core feature set

### Step 5: Auth
**Skill**: `clerk-auth` / `nextjs-supabase-auth`
- Set up user authentication
- Manage user sessions
- Handle permissions

### Step 6: Payments
**Skill**: `stripe-integration` / `stripe-automation`
- Integrate payment processing
- Set up subscription billing
- Handle invoicing

### Step 7: Landing Page
**Skill**: `frontend-design` / `magic-ui-generator`
- Build marketing site
- Optimize conversion
- A/B test messaging

### Step 8: SEO
**Skill**: `seo-fundamentals` / `seo-aeo-blog-writer`
- Optimize for search engines
- Create content strategy
- Build backlinks

### Step 9: Analytics
**Skill**: `analytics-tracking` / `posthog-automation`
- Track user behavior
- Monitor product metrics
- Set up dashboards

### Step 10: Deploy
**Skill**: `vercel-deployment` / `vercel-automation`
- Deploy to production
- Configure domains and SSL
- Monitor launch

## Completion

SaaS product is launched with payments, auth, and analytics. 💰
