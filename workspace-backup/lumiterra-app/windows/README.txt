LUMITERRA - Aplikasi Windows
============================

Cara pakai:
1. Klik 2x file "Lumiterra.cmd"
2. Game terbuka di jendela tersendiri (tanpa address bar) seperti aplikasi asli
3. Login pakai akun Google kamu

Catatan:
- Butuh Microsoft Edge atau Google Chrome terinstall
- Kalau pakai Chrome, ganti "msedge" jadi "chrome" di file Lumiterra.cmd
- Data login tersimpan terpisah di folder LumiterraApp

Selamat bermain!
